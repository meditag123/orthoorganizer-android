# OrthoOrganizer Android APK builds

This is a **public build-only repository**. The app source stays private in
`meditag123/orthoorganizer-source`. No patient data, Firebase credentials,
or GitHub tokens belong in this repository.

## One-time configuration

1. Open the [fine-grained token page](https://github.com/settings/personal-access-tokens/new).
2. Create a token with **repository access: Only select repositories** →
   `meditag123/orthoorganizer-source`, and **Contents: Read-only**.
   Choose a suitable expiration and renew it when it expires.
3. Open [Actions secrets](https://github.com/meditag123/orthoorganizer-android/settings/secrets/actions)
   in this repository, choose **New repository secret** and set the name
   `ORTHO_SOURCE_READ_TOKEN`. Paste the token as its secret value.
4. Open [Actions](https://github.com/meditag123/orthoorganizer-android/actions/workflows/android-apk.yml),
   choose **Run workflow**. After the Android job succeeds, download the
   `OrthoOrganizer-Android-APK` artifact and extract `app-release.apk`.

Never paste a token into issues, README, workflow files, or chat.

The workflow runs on GitHub-hosted public-repository runners and builds the
latest private source. Scheduled weekly builds help keep the workflow active.

**Important:** Flutter's autogenerated debug signing for release APK is not
a stable production signing key. For an in-place upgrade from an earlier APK,
the new build must use the **same Android signing key and application ID**.
Otherwise Android will refuse the upgrade; do not uninstall your existing
app before verifying signing compatibility and protecting local data.
